如何设置

QQ负载监控 → 设置 → 超限持续时长（秒），输入后点击“保存设置”。可设置0—3600秒，默认0秒，关闭面板再打开会保留。

设置实际行为
0秒首轮有效超限采样立即尝试处理。
5秒QQ在所选核心上的合计负载连续超过阈值，累计达到5秒后才尝试处理。
前台与后台共用同一阈值与持续时长。

时长按有效采样窗口累计，达到设定时长后的首次有效采样尝试处理。例如采样间隔2秒、持续时长5秒，通常在累计达到6秒的采样尝试处理。负载回落到阈值及以下、无效数据、过长采样间断、关闭监控或设置变化，都会重新计时。
