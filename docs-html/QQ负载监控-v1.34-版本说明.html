QQ负载监控 v1.34（versionCode 35）。

本次发布包含v1.33的采集器优化和v1.34的新图标。采集器按需解析/proc，复用有界缓冲，按FD软上限缓存实时读取，调度事件直接按字节解析；减少每秒扫描及事件解析分配。保持逐秒精确采集、仅QQ UID范围、完整性校验、前后台识别及双规则。

同一隔离600休眠worker、619总线程场景，旧→新→旧CPU均值9.61% / 6.02% / 14.98%；旧版两轮平均12.29%，新版6.02%，本次固定测试下降51.0%。动态线程数量及设备会影响开销，不能泛化固定降幅；后台47.9℃故障没有复现，长期降温效果待观察。

v1.34图标采用CPU芯片和负载曲线，包含五档PNG、adaptive及monochrome资源；生产Java相对v1.33仅版本常量变化。原签名已安装1.34/vc35，手机APK哈希匹配、26个设置原文保留，3个连续有效核心采样通过。v1.33的1194项JVM、Android原生读取/缓存、固定核心与性能测试为已有验证，本次发布没有重复压力测试。

总负载持续超限规则与单线程持续超限规则分别设置检测、自动处理、阈值和时长，共用CPU0—7选择及采样；前后台采用同一配置。符合实际接口与执行归属的Future/GIF任务按原规则处理，实际返回才确认结束，线程池继续运行。原五版QQ专用Job适配保留；QQ9.3.70/16410仅确认安装及采样，未新增其专用Job停止配置。真实故障任务停止仍待验证。
