QQ负载监控 v1.33 · 采集器优化

2026-10-07。已使用原签名升级安装，QQ已重新加载模块，现有阈值、持续时长、采样间隔和开关设置全部保留。

固定负载下：旧版平均 12.29% → 新版 6.02%，降低约 51%。

改动

  • 复用读取缓冲区，按字段解析进程与线程信息，减少临时对象、正则拆分和垃圾回收。
  • 复用线程文件句柄，以位置 0 读取最新计数；每秒检查线程启动身份、扫描结束清理退出线程的句柄，按系统文件句柄上限限制缓存。
  • 直接按字节批量解析调度事件的数字字段，减少每条事件的字符串构造、UTF8解码和时钟查询。

仍每秒发现进程/线程、检查完整性并发布精确核心快照；前后台查询保持 2 秒周期。监控仅计入 QQ UID 的实际调度运行时间。核心选择、合计和单线程持续超限规则、实际处理策略与UI保持原有行为。
