现在能看到什么

QQ 总 CPU汇总 QQ 所属 UID 所有进程的 CPU 时间增量，包括主进程和同 UID 的工作进程。独立 UID 的隔离进程不在此范围。
进程明细进程名称、PID、采样窗口内的 CPU 占用。
热点线程显示最忙的 12 个线程：线程名、PID、TID、CPU 占用、最后运行核心。线程数量只供查看，不用于判断高负载。
核心频率逐核心显示 MHz。优先硬件读数；回退到驱动请求值时明确标记“驱动”。读不到则显示“频率不可读”。
高负载事件QQ 总 CPU 达到阈值时记录总占用和最忙的 3 个线程，并以 Toast 提示。同一次连续超限只提示一次，恢复后允许再次提示。

百分比口径

单核满载 = 100%。不按整部手机的核心数除成 0–100%。

QQ CPU% = QQ 所有进程 CPU 时间增量之和 ÷ 采样时长 × 100
线程 CPU% = 该线程 CPU 时间增量 ÷ 采样时长 × 100

口径示例（不是设备实测）：QQ 显示 200%–300%，表示约占用 2–3 个核心；4 个核心全满约为 400%。Linux top 的 CPU 百分比说明。

1100 MHz 是频率，百分比是 CPU 时间占用，两者分别显示。驱动请求频率未必等于瞬时硬件实际频率，参见 Linux CPUFreq 文档。

“最后核心”只是线程最近运行的位置。线程可能在采样期间迁移；本版不将整段线程占用归到该核心，也不声称已测得每个核心中 QQ 的完整驻留比例。
